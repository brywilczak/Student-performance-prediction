# Student Performance Analysis and Prediction

## Overview
A Python-based data analysis and machine learning project that explores how demographic factors influence students' academic performance and predicts mathematics, reading, and writing scores.

## Features
- Student demographic analysis.
- Mathematics, reading, and writing score analysis.
- Correlation analysis and heatmap visualization.
- Test preparation impact analysis.
- Academic performance comparison across ethnic groups.
- Predictive modeling using four machine learning algorithms.
- Actual vs. predicted score visualizations.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost

## Machine Learning Models
- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor
- XGBoost Regressor

## Installation

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn xgboost
```

## Run the Project

Ensure `exams.csv` is in the project directory, then run:

```bash
open the file performance_prediction.ipynb in a jupyter notebook
```
